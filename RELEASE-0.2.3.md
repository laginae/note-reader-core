# 0.2.3

- Publish an invented, privacy-safe PDF regression corpus as a stable package export. Desktop, mobile and web tests can compare the same column order, wrapped words, damaged math fonts, Greek letters, repeated text and numeric prose.
- Add golden-result coverage without changing the public reading algorithms.
- This is a shared-library release, not an Obsidian installable plugin. No notes, credentials, provider responses or private PDF files are included.
